## 남은 일

### 직접 해야 하는 것

1. **손쉬운 사용 권한 다시 허용**: `⌄` 클릭 → "권한 허용하러 가기" → Cheoma 켜기. 목록에 이미 켜져 있는데도 안 되면 예전 빌드에 준 권한이다. `tccutil reset Accessibility io.github.m-kim77.cheoma`로 지우고(또는 목록에서 `−`) 다시 허용한다.
2. **팬 도우미 바꾸기**: 예전 이름의 도우미(`com.notchbar.fanhelper`)를 지우고, 팬 탭에서 새 도우미를 설치한다. 지우는 명령은 아래 "작업 기록" 이 날짜 항목에 있다.
3. **팬 1·팬 2가 어느 쪽인지 확인**: 고정에서 "좌우 같이"를 끄고 한쪽만 최대로 올려서 소리로 확인한다. 확인되면 이름을 "왼쪽/오른쪽"으로 바꾼다.
4. **디자인 확인**: 처마 모양 노치를 써 보고 의견 주기. 앱 아이콘도 이 방향으로 만든다.
5. **자체 서명 인증서 만들지 정하기**: 업데이트해도 손쉬운 사용 권한이 유지된다 (무료). Apple Developer Program은 비용 때문에 나중으로 미뤘다 ([DISTRIBUTION.md](DISTRIBUTION.md)).

## 알려진 문제

- macOS 26은 메뉴바가 넘치면 아이콘 순서를 스스로 섞는다. 그래서 실제 메뉴바에 상태 아이콘을 늘리거나 구분자 길이를 바꾸는 실험은 하지 않는다.
- ad-hoc 서명이라 다시 빌드할 때마다 손쉬운 사용 권한이 초기화된다. Developer ID로 서명하면 해결된다.
- 팬 도우미는 앱 실행 파일 경로를 보고 연결을 허용한다. 앱 위치가 바뀌거나 도우미가 새 버전이면 다시 설치해야 한다 (온도 탭에 "다시 설치"가 뜬다).
- 팬의 수동 설정과 온도별 규칙은 앱이 켜져 있을 때만 동작한다. 앱이 꺼지면 도우미가 자동으로 되돌린다.
- IOReport와 SMC는 Apple이 공개하지 않은 인터페이스라 macOS 업데이트로 막힐 수 있다. 막히면 해당 값만 "—"로 나온다.
- 앱 탭은 내 계정 프로세스만 보인다. WindowServer, kernel_task 같은 시스템 프로세스는 권한이 없어 빠진다 (이 맥에서는 1004개 중 637개를 읽을 수 있었다).
- 앱 탭의 "CPU 전력"은 CPU 몫만 추정한 값이다. GPU를 많이 쓰는 앱(게임, LLM)은 실제보다 작게 나온다.
